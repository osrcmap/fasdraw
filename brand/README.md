# fasdraw brand

A sharpened pencil built like a rocket, launched at 45°. Wordmark: Space Grotesk Bold, outlined.

| File | Use |
| --- | --- |
| `logo.svg` / `logo-dark.svg` | mark + wordmark for light / dark backgrounds |
| `mark.svg` | the mark alone |
| `mark-mono.svg` | one colour (`currentColor`), for stamps, embossing, single-ink print |
| `icon.svg` | app icon / avatar on a dark rounded square |
| `../public/favicon.svg` | the mark cropped tight for small sizes |

## Rebuild

Every file is generated by `build.py` from one definition of the shapes and colours. Edit it, then:

```sh
npm pack @fontsource/space-grotesk@5 && tar xzf fontsource-space-grotesk-*.tgz
pip install fonttools
python3 brand/build.py package/files/space-grotesk-latin-700-normal.woff
```
